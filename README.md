# AI Chatbot (Gemini AI)

A full-stack AI chatbot built using the MERN stack and Google Gemini API.

## Features
- JWT Authentication
- Persistent Chat History
- Google Gemini API Integration
- Pinecone Vector Memory
- Socket.IO Real-time Messaging
- MongoDB Database

## Tech Stack
- React.js
- Node.js
- Express.js
- MongoDB
- Redux Toolkit
- Google Gemini API
- Pinecone
- Socket.IO
